# report —— 设计报告与大模型协作记录

本目录对应官方提交要求 3.1.1.3「设计报告」，包含：

| 文件 | 内容 | 对应官方要求 |
|---|---|---|
| `design_report.docx` | 设计报告（作品报告格式：摘要 + 五部分 + 参考文献，含图表 21 幅/表 13 张） | 七项要求逐项对应（见下表） |
| `llm_collaboration_log.md` | 大模型协作记录：提示词、模型回答要点、自我纠错轨迹、智能体工作流设计 | 报告 §2.7 的展开版（逐条全文） |

> 设计报告为可编辑 Word 文档，目录为 Word TOC 域：打开后全选（Ctrl+A）按 F9
> 可自动刷新页码。完整版《技术报告》因提交包体积限制未随包，其结论性数据均已
> 摘入设计报告并标注来源。

## 设计报告章节与官方七项要求对照

| 官方要求 | 报告位置 |
|---|---|
| 选题背景与创新点 | 摘要 + 1.2 应用领域 + 1.5 主要创新点 + 2.1 方案论证（含前人工作 [2][3] 对比） |
| 设计原理与功能框图 | 2.1–2.3（图 3 总体框图、图 6 BD 标注、图 12 软件架构、图 16–18 等） |
| 软硬件划分依据与接口设计 | 2.1 方案论证 + 2.2.3 四类接口 + 表 2 地址映射 + 表 3 引脚分配 + 2.2.4 理论计算 |
| 优化过程（含前后对比表） | 1.4 末段（两阶段网络优化）+ 2.5 六条问题与解决 + **表 B 优化前后对比** |
| 大模型协作记录 | **2.7（表 C 八案例 + 智能体工作流设计）** + 4.2 心得体会 |
| 技能包提炼过程 | **2.8（表 D 来源—验证 + PYNQ 边界声明）** |
| 复现说明 | **2.9（九步，从零开始，对应本仓库目录结构）** |

## 阅读建议

- 先读报告摘要与第一部分了解系统，第二部分 2.7/2.8/2.9 为官方要求的协作/技能/复现专节；
- 大模型协作与智能体工作流的全量逐条记录读 `llm_collaboration_log.md`（对应 §2.7 的展开）；
- 电路/外设/驱动级细节以工程内源码与文档为准（`src/vitis_workspace/.../src/docs/` 四份设计文档）。
