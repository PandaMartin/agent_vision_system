# 提示词工作流：XDC 约束文件完整性审查

## 适用范围
Zynq/Vivado 工程的引脚约束整理、报告撰写、约束迁移核对。与 EDA 工具版本无关。

## 使用方法
1. 让模型先用正则批量提取 `set_property PACKAGE_PIN / IOSTANDARD` 行，输出初表；
2. 必须追加第二问："列出所有不以单行 set_property 形式书写、或 get_ports 花括号跨行的约束"（本工程 TTC0_WAVE0/1 两条 PWM 约束即为拆行写法，首轮正则全部漏掉）；
3. 与 Vivado 工程内实际端口交叉核对（GUI 的 I/O Planning 或 Tcl 的 `get_ports`），以工具侧为准合并。

## 提示词模板
```
以下是 <文件名>.xdc 全文。请输出引脚分配表（信号组/信号名/引脚/电标准）。
要求：① 先提取单行 set_property 约束；② 再单独扫描多行/拆行写法（同一 net 的
PACKAGE_PIN 与 IOSTANDARD 分两行、或大括号跨行）；③ 输出两类合计的总数，
并逐条标注来自哪一行。
```

## 已验证效果
本工程 pin.xdc 经该流程从首轮 53 项修正为 55 项，与工程实际端口一致，产出技术报告"关键信号引脚分配"表。

## 失效条件
工程改用 block-level 约束或 IP 内嵌约束时，正则与 get_ports 均需相应扩展；本流程不校验电气正确性。
