# 提示词工作流：引用文献逐条溯源

## 适用范围
竞赛/论文写作中由大模型推荐的参考文献核验。领域无关。

## 使用方法与提示词模板
```
为 <主题> 查找近三年相关文献，每篇给出：题目/作者/期刊或会议/卷期页码/DOI 或 URL。
规则：① 只输出你能给出可访问地址的文献；② 地址必须指向出版方或预印本官网；
③ 无法给出地址的一律不要列出。
```
拿到候选后人工逐条打开地址核对卷期页码；模型主动追加的文献默认视为未核验。

## 已验证效果
本队技术报告最终保留 5 篇引用，全部经地址核验（Sensors 26(5):1626、JESA 59(1):157-166、IEEE CEM 14(4):76-86、Forests 16(4):698、arXiv:2509.04153）。过程中模型曾先行引用 2 篇未确认文献，按本流程补核后才保留——即该工作流价值的直接例证。

## 失效条件
出版方页面改版导致地址失效；预印本与正式版并存时需人工确认以哪个版本为准。
