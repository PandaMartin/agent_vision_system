# 提示词工作流：框图/截图识别的幻觉防护

## 适用范围
让视觉模型读取 Vivado 框图截图、示波器照片等"小字号 + 专业名词"图像并转写成文字的场合。

## 使用方法（三步防护）
1. 先取真值：从机器可读源（BD 的 .bd JSON、网表、日志）提取"合法名词清单"；
2. 受约束选择：提示词限定"该名称是且仅是清单之一，清单外回答 none 并给出原始逐字符转录"；
3. 像素级抽查：对每个读出的名称做位置/字形复核（放大裁剪、逐字符比对），两种方法不一致的丢弃重读。

## 提示词模板
```
该徽章文本是且仅是以下 N 个之一：<清单>。是哪一个？
若确实都不是，回答 none 并逐字符转录你看到的原始文本。禁止推测清单外的名字。
```

## 已验证效果
本队 BD 截图 17 个模块标注：无防护时视觉模型两次误读（DVI 发送 IP 被认成采集 IP；时钟 IP 副标题"Clocking Wizard"被读成不存在的模块名），加防护后 17/17 与 system.bd 对齐，产出设计报告图 2。

## 失效条件
真值清单本身不可得的场合（无机器可读源）退化为纯人工核对；本流程不解决图像本身模糊。
