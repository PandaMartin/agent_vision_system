# src/sd —— SD 卡加载内容的源码树

板上从 SD 卡动态加载的两类东西，源码统一放这里开发（目录结构与 SD 卡对应）：

```
src/sd/
  apps/      SD加载的应用 —— 每个应用一个文件夹，sdapp.py 编译封包成 <名>.bin
             推送/安装到板卡 SD:/apps/（桌面出图标）。开发见 docs/应用开发指南.md
  models/    模型程序模块 —— 每个模型一个文件夹（文件夹名=模型名），nnmod.py
             编译封包成 model.mod，与模型数据文件一起放 SD:/models/<模型名>/。
             规则见 docs/模型平台化设计.md
```

共同纪律：

- 文件夹名即身份：应用 bin 名、模型名都由文件夹派生，改名=换身份；
- 这两个目录**不参与固件编译**（CMake 不扫描），产物靠各自工具独立构建；
- 推送通道：应用走 `tools/netpush`（网口），模型走 SD 卡拷贝。
